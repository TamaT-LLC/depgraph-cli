# depgraph v0.4.0-rc.6

This release candidate republishes the complete `0.4.0` release closure with
the current benchmark metric contract bound into the stable release gate. It
supersedes rc.5, whose quality, hostile, benchmark, five normal packages, five
compiler packs, and both aggregate verifiers completed successfully, but whose
stable gate retained the older eleven-metric count after the v6 report expanded
to thirteen metrics.

The stable gate now requires the exact ordered v6 metric set: thirteen named
metrics with eleven gated and two cold-query observations. Every gated metric
must pass, while a missing, additional, reordered, renamed, or reclassified
metric fails closed. This matches the benchmark producer's existing contract
instead of accepting a count-only approximation.

This candidate preserves rc.5 target-native release verification. Each normal
package executes its bounded query and profile planner twice, requires exact
within-target byte stability, and compares the measured identities to the
compiled five-target expectations. The aggregate and stable gates retain those
exact identities through archive checksums and reject syntactically valid
forged sidecar digests. Target-independent runtime, framework-build,
cross-language, schema, and license artifacts remain byte-identical aggregate
requirements.

Release staging also preserves the canonical UTF-8/LF contract assets and the
Windows ZIP executable modes for `.exe`, `.cmd`, and `.bat` files.

## Compiler-pack assets

Each of the five supported targets publishes these assets in addition to the
normal depgraph archive:

- `depgraph-compiler-pack-0.4.0-<target>.tar.gz` (or `.zip` on Windows)
- the matching `.sha256` sidecar
- `depgraph-compiler-pack-0.4.0-<target>.requirement.json`
- `depgraph-compiler-pack-0.4.0-<target>.smoke.json`

The aggregate `compiler-pack-verification.json` binds all five packs.
`stable-release-gate.json` binds that report to the normal archive matrix and
rejects a missing target, version or target drift, failed semantic smoke,
tamper/rollback failure, or a failed compiler-pack workflow job.

Download and extract the matching pack next to its requirement document, then
verify it before running project code:

```text
depgraph doctor --compiler-pack-requirement compiler-pack-requirement.json
depgraph resolve --build PATH --allow-project-code --rust-compiler-precise \
  --compiler-pack-requirement compiler-pack-requirement.json
```

See the compiler-pack section in the README for platform-specific checksum and
extraction commands. No rustup, PATH, system, project-toolchain, or alternate
backend fallback is attempted.
