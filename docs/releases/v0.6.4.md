# depgraph v0.6.4

`v0.6.4` は v0.6.3 に対する stable patch release であり、外部依存パッケージの検索と Web ルートから実装への依存追跡を改善する。
公開の完了には、署名付き tag、GitHub Release、同一 source の公開後証跡を必要とする。

## 外部依存パッケージの検索

`package:` セレクターで、npm などの外部依存パッケージも指定できる（[#529](https://github.com/TamaT-LLC/depgraph-cli/pull/529)）。
`package:stripe`、`package:stripe@18.0.0`、`package://npm:stripe@18.0.0#node_modules/stripe` のように、名前・バージョン・完全な locator で検索する。
候補が複数ある場合は一つに推測せず、完全な安定 ID を使って選択する。
意味解析の `external://` 境界は、パッケージを表すノードとは区別する。

## Web ルートから実装への追跡

Next.js、Astro、TanStack Router / Start の意味解析ルートから、実装 symbol または宣言 file へ到達できるようにする（[#530](https://github.com/TamaT-LLC/depgraph-cli/pull/530)）。
ルートを入口に依存関係をたどり、実装を変更したときの影響を調べられる。
ルート・コンポーネント・境界を結ぶ証拠の検証と、対応する回帰テストを追加する。

## 診断と利用案内

TypeScript の `typeof` による型クエリーの証拠を、意味解析チェックが正しく受け付けるよう修正する（[#526](https://github.com/TamaT-LLC/depgraph-cli/pull/526)）。
Next.js の build link テストでは、macOS の一時ディレクトリを実パスへ正規化する（[#531](https://github.com/TamaT-LLC/depgraph-cli/pull/531)）。

README を導入の入口として整理し、インストール・使い方・互換性の説明を日英のガイドへ分ける（[#528](https://github.com/TamaT-LLC/depgraph-cli/pull/528)）。
詳しい動作と検証方法は `docs/reference/` から参照できる。

## Release source and verification

1. version change、release note、ADRを一つのPRにまとめ、CI成功とGreptileの未解決指摘ゼロを確認してマージする。
2. `main`を一時freezeし、そのcommitで`extra_native_packages=true`を指定したmanual Full CIの10ジョブすべてを成功させる。Intel macOS（`macos-15-intel`）は対象外である。
3. `refs/heads/release/0.6`を同じcandidate SHAに作成する。既存refならfast-forwardで更新する。
4. `v0.6.4`のsigned annotated tagを同じsource SHAへ作成する。
5. Release workflowで4 targetのarchive、compiler pack、checksum、manifest、SBOM、license、MCP smokeを検証する。`x86_64-apple-darwin` は構築しない。
6. 公開後にasset closure、stable gate、code-health CLI/MCP parity、Agent host canaryを検証し、`release-post-publish-evidence-v0.6.4.json`を同じReleaseへ追加する。
7. GitHub Releaseと証跡が成立した後に、npm workflowを`v0.6.4`へdispatchする。

`v0.5.4`のtag object、peeled source、asset、evidenceをv0.6.4のcandidateとして再利用しない。

v0.6.4は`@tamat-llc/depgraph`と`@tamat-llc/depgraph-win32-x64`を含む4 targetのnative packageを公開する。`@tamat-llc/depgraph-darwin-x64` は公開しない。
npm publicationには`npm Trusted Publishing`を使い、Node.js 24以上を要求する。
musl targetは対象外であり、`v0.6.4`のnative jobは`mcp-package-smoke-v3`を使う。
stable gateは製品価値の`agent-dogfood-report-v1`に加え、Issue #436のcode-health `agent-dogfood-report-v2`を14 gateで検証する。
code-health reportは`fixtures/agent-dogfood-v2/evidence/v0.5.4-rc.2/report.json`に固定する。
code-health reportの固定SHA-256は`7cb90ae38161e375ac080f475de6c8ab36dc18afc3ce243f6cdf7306d759547f`である。

## Support status
