# depgraph v0.7.4

v0.7.4 は、Go の分割スキャンと Rust のツールチェーン確認で繰り返す処理を減らすパッチリリースです。
変更は main の `3b1c3a58` を基点とします。

## Go の分割スキャンで重複するノード出力を減らす

Go の `staged_bodies` 解析で、各バッチがパッケージ全体の宣言ノードを繰り返し出力する処理を減らします（[#645](https://github.com/TamaT-LLC/depgraph-cli/pull/645)）。
各バッチは、担当ファイルの宣言と、そのバッチの依存関係が参照する宣言を出力します。
分割なしの解析と、全バッチを統合した解析で、同じグラフになることを回帰テストで確認しています。

## スキャン中のツール確認で重複する読み込みを減らす

同じスキャン中は、変更のない worker とツールチェーンのハッシュを再利用します（[#644](https://github.com/TamaT-LLC/depgraph-cli/pull/644)）。
ファイルの同一性を再確認し、置き換えや書き換えを検出した場合は読み直します。
チェックポイントの保存時には、ツールのバージョン確認を再実行します。

Rust worker も、ツールのハッシュとツールチェーンの確認結果をプロセス内で再利用します（[#643](https://github.com/TamaT-LLC/depgraph-cli/pull/643)）。
ファイルや環境の変化を検出した場合は、確認結果を取り直します。

## ビルドと検証の待ち時間を減らす

配布パッケージの Rust ビルドをまとめ、独立した検証を並行して実行します（[#658](https://github.com/TamaT-LLC/depgraph-cli/pull/658)、[#659](https://github.com/TamaT-LLC/depgraph-cli/pull/659)）。
compiler pack の準備も、driver のビルドと並行して進めます（[#653](https://github.com/TamaT-LLC/depgraph-cli/pull/653)）。
CI のキャッシュとテスト構成を見直し、変更に無関係な重い検証の実行を減らします。

内部の Rust crate を整理し、Agent の DTO を `depgraph-agent-contract`、契約抽出処理を `depgraph-contract-scan` に分けます（[#640](https://github.com/TamaT-LLC/depgraph-cli/pull/640)、[#641](https://github.com/TamaT-LLC/depgraph-cli/pull/641)）。

## Release source and verification

1. version changeとrelease noteを一つのPRにまとめ、CI成功と未解決のレビュー指摘ゼロを確認してマージする。
2. `main`を一時freezeし、そのcommitで`extra_native_packages=true`を指定したmanual Full CIの10ジョブすべてを成功させる。
Intel macOS（`macos-15-intel`）は対象外である。
3. `refs/heads/release/0.7`を同じcandidate SHAに作成する。
既存refならfast-forwardで更新する。
4. `v0.7.4`のsigned annotated tagを同じsource SHAへ作成する。
5. Release workflowで4 targetのarchive、compiler pack、checksum、manifest、SBOM、license、MCP smokeを検証する。
`x86_64-apple-darwin` は構築しない。
6. 公開後にasset closure、stable gate、code-health CLI/MCP parity、Agent host canaryを検証し、`release-post-publish-evidence-v0.7.4.json`を同じReleaseへ追加する。
7. GitHub Releaseと証跡が成立した後に、npm workflowを`v0.7.4`へdispatchする。

`v0.5.4`のtag object、peeled source、asset、evidenceをv0.7.4のcandidateとして再利用しない。

v0.7.4は`@tamat-llc/depgraph`と`@tamat-llc/depgraph-win32-x64`を含む4 targetのnative packageを公開する。
`@tamat-llc/depgraph-darwin-x64` は公開しない。
npm publicationには`npm Trusted Publishing`を使い、Node.js 24以上を要求する。
musl targetは対象外であり、`v0.7.4`のnative jobは`mcp-package-smoke-v3`を使う。
stable gateは製品価値の`agent-dogfood-report-v1`に加え、Issue #436のcode-health `agent-dogfood-report-v2`を14 gateで検証する。
code-health reportは`fixtures/agent-dogfood-v2/evidence/v0.5.4-rc.2/report.json`に固定する。
code-health reportの固定SHA-256は`7cb90ae38161e375ac080f475de6c8ab36dc18afc3ce243f6cdf7306d759547f`である。
